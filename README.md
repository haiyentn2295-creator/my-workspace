## 📂 Cấu Trúc Workspace

```
my-workspace/
├── AGENTS.md                    # Quy tắc vận hành (quan trọng nhất)
├── README.md                    # File này — hướng dẫn tổng quan
│
├── .agents/                     # Cấu hình AI Agent
│   ├── skills/                  # Kỹ năng chuyên môn (tạo từ Buổi 3)
│   ├── rules/                   # Quy tắc vận hành (tạo từ Buổi 6)
│   └── workflows/               # Quy trình tự động (tạo từ Buổi 4)
│
├── knowledge-base/              # Tri thức nội bộ (tạo từ Buổi 6)
│   └── my-profile.md            # Hồ sơ cá nhân / chuyên môn
│
├── sample-data/                 # Dữ liệu thực hành
│   └── README.md
│
└── outputs/                     # Kết quả AI tạo ra
    ├── drafts/                  # Bản nháp
    └── reports/                 # Báo cáo
│
└── docs/                        # Tài liệu quản lý workspace
    ├── pdca-log.md              # Nhật ký PDCA (bắt đầu từ Buổi 2)
    ├── workspace-map.md         # Bản đồ workspace (cập nhật theo buổi)
    └── lesson-checkpoint-log.md # Ghi chú checkpoint từng buổi
```
