# 📁 Sample Data — Dữ Liệu Thực Hành

Thư mục này chứa dữ liệu bạn sử dụng để thực hành với AI.

## Hướng Dẫn

1. **Đặt dữ liệu thật** liên quan công việc của bạn vào đây
2. **Ẩn danh hóa** nếu dữ liệu chứa thông tin nhạy cảm (tên KH, số điện thoại...)
3. **Đặt tên file** rõ ràng: `ten-du-lieu_ngay.csv` hoặc `ten-du-lieu_ngay.xlsx`

## Dữ Liệu Nên Có

Dựa trên lĩnh vực của bạn, cố gắng có ít nhất 1 file trong mỗi loại:

| Loại dữ liệu | Ví dụ | Buổi học sử dụng |
|-------------|-------|-----------------|
| Dữ liệu định lượng | Doanh số, KPI, số lượng | S02, S06, S08 |
| Dữ liệu văn bản | Feedback, email, báo cáo | S03, S05 |
| Dữ liệu có lỗi | File cần làm sạch | S09 |
